# Python Study Progress

Structured Python exercises completed during a coding course, organized by stage — from language fundamentals through object-oriented programming. Folder names are in Estonian (the language the course was taught in); code and comments are in English.

## Structure

### 1. Sissejuhatus (Introduction)
Core language fundamentals: variables & code style (PEP 8), math expressions, functions & parameters, booleans & conditionals, strings, for/while loops, lists, tuples, dictionaries, sets.

### 2. Jätk (Continuation)
Builds on the fundamentals: operators, error handling, more functions/conditionals, loops, data structures, **unit testing**, file reading/writing, plus a bonus section touching OOP, regex, and scheduling.

### 3. OOP (Object-Oriented Programming)
Progresses from procedural exercises (math, strings, lists, dicts) into OOP: classes & objects, constructors & methods, encapsulation & modularity, and object composition (using objects within other objects/functions).

## Notable

The `2. Jätk/6. Testimine` folder includes actual unit tests (`test.py`) written for each exercise (e.g. lottery simulation, fruit ordering, student study tracker) — practice verifying code correctness, not just writing it.

Each subfolder has its own README with notes on the specific exercise.
